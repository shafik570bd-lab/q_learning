# কোচিং ম্যানেজার — চালু করার নিয়ম (একবারই করতে হবে, ~১০ মিনিট)

কোনো কমান্ড চালাতে হবে না। ডাটাবেসের টেবিল ও ডেমো অ্যাকাউন্ট অ্যাপ নিজেই প্রথমবার তৈরি করে নেয়।

1. github.com এ অ্যাকাউন্ট খুলে এই প্রজেক্টের ফাইলগুলো একটি নতুন repository তে আপলোড করুন।
2. vercel.com এ "Continue with GitHub" দিয়ে লগইন করুন → **Add New → Project** → repository টি **Import** → **Deploy**।
3. Vercel প্রজেক্টে **Storage** ট্যাব → **Create Database** → **Neon (Postgres)** → **Connect**। (ডাটাবেসের লিংক নিজে থেকেই বসে যাবে)
4. **Deployments** → সর্বশেষটির ⋯ → **Redeploy**।
5. এখন `https://আপনার-প্রজেক্ট.vercel.app` লিংকটিই আপনার স্থায়ী সাইট।

## অ্যাপ/APK
- ফোনে Chrome দিয়ে লিংক খুলুন → ⋮ → **Install app**।
- APK চাইলে: pwabuilder.com এ লিংক দিন → Package for stores → Android → Download। ফাইলটি WhatsApp এ সবাইকে পাঠান।
